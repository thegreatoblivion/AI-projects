# Personal Projects Collection

A curated collection of my small, personal programming projects, with a strong focus on reinforcement learning and neural networks.

This repo showcases projects I’ve built, explored, or learned from as I deepen my understanding of AI/ML and their practical applications. 

These projects are solely for learning and experimentation.

## Reinforcement Learning

Unity ML-Agents–based reinforcement learning environments focused on control and multi-agent interaction.

### Projects

| Project | Description | Language |
|-------|------------|------|
| **Balance Agent** | Agent learns to balance a moving ball on a platform using discrete rotation actions and continuous reward feedback |Unity, C#|
| **Hide and Seek Agent** | Multi-agent environment where a seeker learns to find the hider while the hider learns to survive longer |Unity, C#|
